Bulk Create Students

Create the roster for a new semester from a list of names. Meant to be used only once per semester, right after admissions. Only available to superusers.

Instructions
  • Select a semester that has not yet ended
  • Paste one airtable_name per line, exactly as it appears in Airtable
  • Classes and houses are not set here. Students choose their name and fill in the registration questionnaire from the student invite link, and their classes and houses are applied later from Upload Class Assignments.
  • Names that already exist for the semester are left alone
  • All validation happens before any data is saved - errors will abort the entire operation
