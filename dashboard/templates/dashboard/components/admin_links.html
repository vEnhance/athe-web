Admin

The Django Admin allows the execution of arbitrary changes to the database. For most one-off changes, this is where you can go.

The rest of the links are used mostly at the start of the semester for certain bulk operations that are too tedious to do in Django Admin. Once the semester has started, you mostly won't need them anymore.

  • Admin Manual: Instructions manual.
  • Bulk Create Students: Mass create Student objects for the new semester after admissions.
  • Class Logistics: Mass edit details for course like meeting time, Zoom link, Google Classroom.
  • Download Responses: Download all the responses from the registration questionnaire.
  • Incomplete Registrations: See a list of accepted students who didn't finish the registration flow.
  • Upload Assignments: Import a JSON of class and house assignments computed by a solver.
